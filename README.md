# DevOps-Principles-
DevOps Research Project
This repository contains a beginner-friendly research report, a tool comparison matrix, a presentation, and a CI/CD pipeline diagram.
Contents
- README.md — project overview and key takeaways
- docs/devops_principles.md — DevOps history, Agile vs Waterfall, the Three Ways, CI/CD lifecycle and benefits
- docs/tool_comparison.md — comparison of containerization, Infrastructure as Code (IaC), and monitoring tools
- presentation/devops_overview.pptx — presentation deck
- presentation/devops_overview.pdf — PDF version of the slides
- assets/pipeline_diagram.png — CI/CD pipeline workflow diagram
- assets/pipeline_diagram.svg — scalable version of the diagram
Key takeaways
DevOps is a culture and set of practices that bring software development and IT operations together. It aims to deliver value more frequently and reliably through shared ownership, automation, fast feedback, measurement, and continual improvement. Tools help, but tools alone do not create DevOps.
How to use
1. Read docs/devops_principles.md.
2. Review docs/tool_comparison.md.
3. Open the presentation in PowerPoint or view its PDF version.
4. Use assets/pipeline_diagram.png in your report or presentation.
5. Upload the files and folders to your GitHub repository.
